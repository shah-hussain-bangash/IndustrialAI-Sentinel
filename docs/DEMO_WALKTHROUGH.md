# Demonstration walkthrough

## 1 Inspect condition

Sign in as Engineer. Operations overview shows stored sensor trends, the computed fleet condition index, active episodes and assets requiring attention. Open an asset card to inspect current measurements, a trend and contextual limits. Use site selection to constrain visible records.

## 2 Exercise live simulation

Open Live monitoring. Select P-101 and choose Rising vibration. Step once or start streaming. Inspect vibration and temperature tabs. Pause before leaving the browser unattended. The simulated readings are saved; restarting the app does not reset your work.

## 3 Investigate evidence

Create an investigation from the asset. Review observed facts separately from possible causes. Open Source evidence and inspect an actual source page. Edit the recommendation or checklist if needed. The server creates a new immutable revision and invalidates previous approval.

## 4 Review independently

Open the account menu and choose Approver. Open the investigation, review sources, acknowledge your review and enter a decision reason. Approve the version or return it for revision. The backend prevents the current author from self-approving.

## 5 Plan and dispatch

Switch to Planner. Open the approved investigation and use Review & action to create a work order. Set its technician and due date. Open the order and enable Test uncertain response before dispatch. The persistent simulator accepts the command while the app marks the outcome as uncertain.

## 6 Reconcile and complete

Choose Reconcile existing order. Confirm that a single external simulator reference appears. Switch to Technician, record actual findings and complete the in-progress order. Inspect Activity & audit to trace the sequence.

## 7 Add and query documents

As Engineer upload an authorized text-based PDF or text file with site and equipment applicability. Search its terminology in Knowledge base and open returned sources. Sign in manually as `restricted@sentinel.local` to verify that Ruwais sources and assets are unavailable.

## 8 Inspect the implementation

Open the backend `/docs`, inspect actual API contracts, run tests, reproduce synthetic model evaluation and review `IMPLEMENTATION_STATUS.md`. Describe tested local behavior and unverified enterprise extensions separately when presenting the work.
